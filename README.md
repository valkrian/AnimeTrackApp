# Anime Season Tracker

## Prerequisites
- Node.js 20+
- pnpm 9+
- Docker (optional, for database later)

## Install
```bash
pnpm install
```

## Run
Backend (NestJS):
```bash
pnpm dev:backend
```

Frontend (Vite):
```bash
pnpm dev:frontend
```

## Build
```bash
pnpm build
```

## Lint + Format
```bash
pnpm lint
pnpm format
```
